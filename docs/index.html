Flash two boards, leave one behind, and walk away with the other plus this page.

Connect to either board — each one reports what it can hear, so the numbers are for the link between them. Tap Connect a board again to add the second one.

For a range walk, drop one board, tap set base where you left it, turn on GPS, and walk. Every packet gets pinned to where you were standing when it arrived, so bare track is ground where nothing got through.

Needs Chrome on Android or desktop. Web Bluetooth won't work from a file:// page — use the GitHub Pages URL, or python3 -m http.server and open http://localhost:8000.
